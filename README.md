# URL Shortener & QR Generator - Frontend

Modern Next.js web app for shortening URLs and generating QR codes.

## Features
- ✂️ Clean UI for URL shortening
- 📱 Instant QR code generation & download
- 📱 Fully responsive design
- ⚡ Server-side rendering with Next.js

## Tech Stack
- **Next.js 14** - React framework
- **Tailwind CSS** - Styling
- **Axios** - API requests
- **React Hook Form** - Form handling

## Quick Start
```bash
# Install dependencies
npm install

# Run development server
npm run dev
